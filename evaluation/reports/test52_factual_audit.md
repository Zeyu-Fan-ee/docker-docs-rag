# RAGAS 事实正确性五题复核

从正式基线选择三道人工通过但自动得零分的题（TEST04、TEST28、TEST40），一道实际漏答题（TEST14），以及一道首轮两边都通过的对照题（TEST06）。使用保存的相同回答和参考答案，沿用 RAGAS 0.4.3、DeepSeek Flash、temperature 0 和 4096 输出上限，只复跑 Factual Correctness 并保存逐条判定。首轮只有分数，下面的具体判定理由来自复跑。

| 题号 | 首轮 → 复跑 | 人工核查与评审判定 |
|---|---:|---|
| TEST04 | 0 → 0.50 | 题目允许任选一种命令。回答使用等价的 source/target，评审以参考只写 src/dst、路径不同为由否定，并将未提供第二种可选写法也判为缺失。 |
| TEST28 | 0 → 0 | 评审认可回答覆盖参考里的三个步骤。正向核查却把步骤与 --rm、ubuntu 和源目录等细节一起判，因短参考没写这些细节而全部判为不支持。实际引用的 Docker 文档给出了该命令。 |
| TEST40 | 0 → 0 | 评审认可回答覆盖默认 TCP 和查询 UDP 两点。正向核查因参考没有复述题干中的命令名、使用条件或示例而将三条陈述全部判为不支持。 |
| TEST14 | 0 → 0 | 评审认可 -v 创建目录，确认漏答默认 --mount 报错。正向核查把有依据的创建目录行为和参考没写的权限细节合并判定，进一步压低分数。 |
| TEST06 | 1.00 → 0 | 同样输入的两次评分有明显变化。复跑时评审认可回答覆盖参考核心结论，但反向核查指出回答写了 Docker Engine 等参考未复述的实体，也指出「可以访问」与「可能访问」的措辞差异。 |

这里的 Factual Correctness 用默认 F1 口径，先把回答拆成陈述，让评审判断参考答案是否支持它们，再从参考答案反查遗漏。此处评审输入是回答与参考答案，题干和检索片段不随该指标传入。若正向核查没有一条获支持，即使反查确认必答点齐全，最终仍可能为 0。

五题说明了实际漏答、参考上下文不足、等价写法误判和重复评分波动。样本按典型案例挑选，无法估计这些问题在 44 题中的比例。报告保留首轮均分 0.240 和人工必答点覆盖率 39/44，复跑分数只用于诊断。
