# 相邻片段生成小样本

使用已保存检索结果和同一 DeepSeek Flash、temperature 0、相同提示词，对 DEV03 与 DEV05 分别生成基线和补相邻片段的答案。每种设置各生成一次。选这两题是因为前一轮开发集文字覆盖变化，属于探索性案例，不能当作独立测试或估计整体提升。

| 题目 | 基线与相邻结果 | 证据核查 |
|---|---|---|
| DEV03 tmpfs | 基线说明数据临时、停止后丢失和 swap 例外，未明确说挂载移除。相邻结果补充挂载移除及上述要点。 | 相邻结果 [4] 明确包含停止时移除挂载及文件不持久保留，[2] 支撑 swap。此轮必答点由部分覆盖变为完整覆盖。 |
| DEV05 bridge | 两版均解释 DNS 差异和自定义网络隔离，均没有给出具体动态连接区别。 | 两版对 DNS 和自定义网络的引用可支撑其相关结论。相邻答案关于跨主机通信应使用 overlay 的补充，所标 [2] 只说明同主机网络及 overlay 适用情况的一部分，需对照实际上下文谨慎复核；不据此计入必答点。 |

DEV03 的补充来自新加入的相邻片段，DEV05 仍有内容未得到扩充。只有各一次生成，无法排除生成模型波动。原始记录保留上下文、引用顺序和用量。独立验证题、拒答题以及端到端质量尚未评估。
