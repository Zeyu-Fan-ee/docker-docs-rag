## NEW01 — tmpfs 与内存限制
**问题：** 某容器设置了内存限制，还把 tmpfs 的大小设得很大。根据文档，增大 tmpfs 大小能让该容器使用超过自身限制的额外内存吗？

**拟定答案：** 不能。tmpfs 使用的内存计入容器的内存限制；把 tmpfs 大小设大不会提高这个限制，写满仍可能导致容器内存不足。

**必答点：** tmpfs 使用计入容器内存限制；增大 tmpfs 大小不提高容器限制。

**通俗解释：** tmpfs 的大小上限和容器总内存上限是两道不同的限制，调大前者不会自动调大后者。

**依据：** `data/docker_official/raw/content/manuals/engine/storage/tmpfs.md:23-26,57-58`。

## NEW02 — tmpfs 能否共享
**问题：** 能像共享 Docker volume 一样，在两个容器之间共享 Docker tmpfs mount 吗？

**拟定答案：** 不能；文档明确说明不能在容器之间共享 tmpfs mount。

**必答点：** Docker tmpfs mount 不能在多个容器之间共享。

**通俗解释：** 容器间共享卷和 tmpfs 是不同的挂载方式，不能把卷的共享能力直接套到 tmpfs 上。

**依据：** `data/docker_official/raw/content/manuals/engine/storage/tmpfs.md:53-56`。

## NEW04 — 等待任务成功完成
**问题：** Compose 中，web 必须等一个前置任务成功执行完毕后才启动。`depends_on` 的 condition 可以选什么？

**拟定答案：** 使用 `service_completed_successfully`，表示等待依赖成功完成，再启动依赖它的服务。

**必答点：** `service_completed_successfully`；等待依赖成功完成而不仅是启动。

**通俗解释：** 比如先完成一次初始化任务，再启动应用；这里关心的是任务成功结束。

**依据：** `data/docker_official/raw/content/manuals/compose/how-tos/startup-order.md:18-26`。

## NEW05 — Compose 显式重启依赖
**问题：** 在 Docker 文档的 Compose 示例中，web 对 db 的 `depends_on` 设置了 `restart: true`。如果用 `docker compose restart` 显式重启 db，web 会怎样？

**拟定答案：** web 也会自动重启，以重新建立连接或依赖关系；结论限定于文档所说的显式 Compose 更新或重启操作。

**必答点：** web 也会重启；保留显式 Compose 操作这一条件。

**通俗解释：** 依赖服务被 Compose 显式重启时，让依赖它的服务也重新连接；不能把它扩大成任何崩溃都必然触发。

**依据：** `data/docker_official/raw/content/manuals/compose/how-tos/startup-order.md:32-37,54-56`。

## NEW06 — host 网络模式
**问题：** Compose 服务设置 `network_mode: host` 后，文档如何说明端口映射和服务名 DNS？

**拟定答案：** 容器共享宿主机网络栈；不需要也不支持端口映射，服务名 DNS 解析不工作。

**必答点：** 共享宿主机网络栈；端口映射不需要且不支持；服务名 DNS 解析不工作。

**通俗解释：** 这时容器不再按普通 Compose 服务网络的方式独立映射端口、使用服务名发现。

**依据：** `data/docker_official/raw/content/manuals/compose/how-tos/networking.md:60-63`。

## NEW07 — 不同网络的隔离
**问题：** Compose 定义两个自定义网络：proxy 只加入前端网络，db 只加入后端网络，app 同时加入两者。按照文档示例，proxy 和 db 为什么不能直接互通？哪个服务同时连接两边？

**拟定答案：** proxy 和 db 没有共同网络，所以彼此隔离；app 同时加入两边网络。

**必答点：** proxy 和 db 没有共同网络；app 同时连接两个网络。

**通俗解释：** 把网络想成不同房间：proxy 与 db 不在同一间，app 同时进入两间。

**依据：** `data/docker_official/raw/content/manuals/compose/how-tos/networking.md:90-94`。
