# 12 道开发题的 Judge 对照

固定已有答卷。DEV01–DEV03 使用 dev_pilot_3，DEV04 使用 dev04_deepseek_comparison 的 Top-3，DEV05–DEV12 使用 dev05_12_deepseek 的 Top-3。题干、参考答案和必答点来自 dev_candidates。首三题沿用原先的答卷来源，因此这组答卷用于比较评分，不用于比较生成模型。

## 对照口径

两组使用同一份固定输入、RAGAS 0.4.3、默认 F1、temperature 0、4096 输出上限，保存拆分陈述和双向判定。Gemini 先试 DEV01、DEV04，检查能否返回有效评分和结构化轨迹。通过后，两组各对十道可回答题重复三次。DEV11、DEV12 单独复核拒答。

| 题号 | 人工对照观察 |
|---|---|
| DEV01 | 常规数据保留答到，漏掉 --rm 清理关联匿名卷。 |
| DEV02 | 适用场景的大类答到，缺具体例子和宿主机路径依赖。 |
| DEV03 | 说明了停止后数据丢失和 swap 例外，未明确说挂载被移除。 |
| DEV04 | 卷名和目标路径正确，漏掉启动时自动创建不存在的命名卷。 |
| DEV05 | 答到名称解析和自定义网络隔离。 |
| DEV06 | 答到默认 localhost 指向自身及 host 模式条件。 |
| DEV07 | 答到普通依赖顺序和健康检查。另有「应用可能先于数据库启动」的表述，与依赖顺序混淆，应区分容器启动与应用就绪。 |
| DEV08 | 答到顶层定义、服务授权、挂载路径和 Linux 条件。顶层配置未具体写出来源类型。 |
| DEV09 | 答到环境变量泄露风险和显式授权，未给出文件交付、平台条件及源文件保护。 |
| DEV10 | 答到版本和部分配置规则，未给出运行 Watch 的方式及同步或重建动作。 |
| DEV11 | 合理拒绝提供实际联系人号码。 |
| DEV12 | 合理拒绝确定根因，但把不同示例目录推断成来自同一台主机，缺少依据。 |

人工观察用于核对逐项判定。对比时分别统计等价表达误扣、真实错误或遗漏漏检、同题重复评分翻转和评分失败。缺失评分与零分分别记录。

## 实测结果

DeepSeek Flash 三轮共返回 30/30 个有效分数，轮次均值分别为 0.206、0.302、0.181。第一轮均值按原始记录重算。十道可回答题中，9 道三轮分数不完全相同，4 道在零分与非零之间变化（DEV02、DEV05、DEV06、DEV07）。DEV07 三轮得 0.22、0.20、0，回答侧拆出的陈述数量分别为 8、9、5，说明变化已出现在拆分环节。

DEV01 三次都是 0，但三次反查均确认答到了普通删除后的保留规则，并识别出 --rm 例外遗漏。零分隐藏了这一部分正确。Gemini 对同一答卷给出 0.57，正向认可了两条保留相关陈述，反查也抓住 --rm 的遗漏，但因答案没有区分命名卷和匿名卷，未给常规保留那项通过。因此分数更高不足以判断哪组更接近人工。

Gemini 两题试跑只有 DEV01 成功，DEV04 返回 RateLimitError。后续按用户选择使用 Qwen-Plus 作为第二个评审。

两组评分记录的输入 SHA-256 均与固定答卷一致。以下统计范围是同一批十道可回答开发题。

| 指标 | DeepSeek Flash | Qwen-Plus |
|---|---:|---:|
| 有效分数 | 30/30 | 30/30 |
| 三轮均分 | 0.206 / 0.302 / 0.181 | 0.569 / 0.591 / 0.562 |
| 三轮分数有变化的题数 | 9/10 | 7/10 |
| 零分与非零分之间切换 | 4/10 | 0/10 |
| 逐题最高分减最低分，再取平均 | 0.190 | 0.063 |

Qwen-Plus 在这批答卷上分数波动较小。逐条判定提供了以下例子。

- DEV01 两组都抓到匿名卷清理的漏答。Qwen 三轮都认可回答中多条关于卷数据保留的陈述。DeepSeek 的反查认可常规保留，正向核对三轮都没有通过项。
- DEV04 两组都抓到漏答自动创建命名卷。Qwen 三轮都认可卷类型、卷名和目标路径的写法，但反查时仍将不同示例卷名和路径的完整命令判为不支持。
- DEV09 Qwen 第一和第三轮把未答到的「保护 secret 来源」判成已覆盖，并放过了包含文件交付的复合要点。第二轮拒绝了这两条。三轮总分均较高，单看分数无法看出这两处误判。

这些是开发集上的稳定性统计和案例核查，尚无逐陈述人工一致率。Qwen 可优先用于后续开发集诊断，关键结论仍需人工复核。正式评测的原始 0.240 继续保留。
